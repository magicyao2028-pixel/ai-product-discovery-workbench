# Changelog

## 0.3.0 - 2026-08-13

- Added consented synthetic interview notes with stable note and excerpt lineage.
- Added normalized observation and interpretation review as separate output collections.
- Added lexical-overlap and numeric-support checks that block unsupported observation claims.
- Preserved raw excerpt whitespace and line breaks, and bound supported numbers to declared time, percentage, or currency units.
- Added provenance-rich proposed evidence records without mutating current discovery evidence or the PRD.
- Expanded the offline suite from 23 to 33 tests and updated the report and public demo.

## 0.2.0 - 2026-08-10

- Added dated synthetic feedback linked to stable, versioned requirement IDs and declared evidence.
- Added deterministic support, challenge, and no-effect aggregation with a human-readable change decision log.
- Added a strict approval boundary: recommendations can propose a next version but never mutate a requirement.
- Expanded the sample, Markdown report, static demo, documentation, and test suite to 23 offline tests.

## 0.1.0 - 2026-08-10

- Added validated synthetic discovery packets and evidence relationships.
- Added transparent opportunity scoring and eligibility gates.
- Added requirement inclusion/exclusion, PRD compilation, and traceability rows.
- Added low-fidelity screen filtering, human approval boundaries, tests, documentation, and static demo.
